# programacion-parte-1
# Mesa de ayuda del laboratorio de cómputo

Aplicación (C# y Blazor) para registrar y dar seguimiento a solicitudes de soporte técnico de un laboratorio de cómputo. Permite registrar tickets, encontrarlos en una lista, consultar su detalle y cambiar su estado siguiendo reglas claras.
